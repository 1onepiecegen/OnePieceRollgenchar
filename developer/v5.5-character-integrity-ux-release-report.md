# V5.5 Character Integrity, UX, and Public Release

V5.5 preserves the V5.4 combat, threat, bounty, mode-distribution, and deterministic battle calculations. It adds provenance, presentation, and continuity metadata around them.

## Implemented

- 24 complete curated templates externalized in `database/character-presets.js`; each links a character reference and simulator combat profile.
- Canon presets preserve identity fields instead of displaying a random roll shell. Katakuri, Kaido, Luffy, Teach, and the user-provided Goose OC are targeted regression cases.
- Every character records one creation origin: standard, brutal, guided, unrestricted, canon preset, or OC preset.
- Canon reference bounties and simulator estimates are separate. A known canon bounty is primary only for an unmodified canon preset; an altered preset is marked as an alternate-build estimate.
- Character life records include age, active years, region history, dream, values, fears, timeline, and temporary mentor history. They are narrative metadata and do not modify combat.
- Fruit-origin metadata separates future SMILE records from ordinary Devil Fruits. SMILEs are excluded from the standard pool and require a New World/Wano/Dressrosa-underworld route.
- Sandbox has a dedicated page, guided steps, creator-selected multi-traits, and authored-build provenance.
- Saved characters can reopen unchanged, go directly to Battle, open Poster Studio, and participate in a browser-local export/import backup.
- Battle phases have readable normal/cinematic timing and manual advance; timing stays outside the deterministic battle engine.

## Deliberate limits

This is not a full career simulator, full status-effect battle overhaul, or a complete CSS-by-feature extraction. The old inline compatibility runtime remains while the actual external data, stylesheet entrypoint, preset templates, life records, and release checks are external. All character numeric profiles remain clearly labelled simulator interpretations, not official power values.
