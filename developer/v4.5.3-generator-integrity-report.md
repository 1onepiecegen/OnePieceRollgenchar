# V4.5.3 Generator Integrity Report

Status: accepted integrity pass. Content Batch 02 remains paused.

## Scope

- No combat, progression, threat-weight, bounty-floor, awakening, weapon-rate, or Three Sword formula was rebalanced.
- Government intelligence is now represented as three distinct records: `baselineDossier`, `leakEvents`, and `combinedAssessment`.
- Sandbox tiers are constructed directly from the supplied build and are never reached by searching for a favorable seed.
- Explicit Self-Taught / No Mentor and No Devil Fruit selections are enforced invariants.
- Saved Crew has an opt-in unique-fruit continuity setting.
- Fruit catalog validation rejects duplicate canonical identities and ambiguous menu entries.

## Runtime changes

New modular boundaries:

- `engine/government-intelligence.js` — public Government-assessment facade.
- `engine/sandbox.js` — DOM-free final-build invariants.
- `developer/sandbox-validation.js` — DOM-free targeted tier and Saved Crew continuity checks.

The Developer screen includes **Run 10,000-Build Sandbox Test**. It tests all 17 combat tiers with 589 fixed, reproducible builds each (10,013 total). Unrestricted Creator permits direct values up to 500 solely to make the highest requested tier constructible; standard generation remains capped by the frozen normal generator rules.

## Notes

A random leak is supplemental intelligence, not the source of Government awareness. High-profile Sandbox world-presence selections therefore receive a strong baseline dossier even when there is no leak. A deliberately over-constrained build can still be rejected with a clear explanation if its locks make a requested result impossible; it is not silently rerolled.
