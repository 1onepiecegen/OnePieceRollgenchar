# V5.4 — Grand Adventure Edition

Baseline: V5.3 mechanics and Brutal Grand Line probabilities  
Database version: `5.4.0-grand-adventure-edition`  
Spoiler boundary: end of Wano

## Delivered

- Separate **Standard Adventure** and **Brutal Grand Line** roll modes. Mode is saved on characters and kept separate in personal records.
- Optional, visible Voyage Luck stored only in browser-local session state. It records its streak, milestones, contribution, and reset/disable controls. Brutal never receives Voyage Luck by default.
- Compact Roll 1, Roll 10, and Roll 100 result cards with best-result selection, view, and save actions.
- Readable rarity states for Standard, Brutal, Sandbox, and curated presets.
- Battle presentation phases: decision, telegraph, counter window, impact, resolution, and aftermath; pacing, pause, next phase, 2×/4×, skip, accessible effects, arena themes, replay export, and result metrics.
- A dedicated local-only Wanted Poster Studio with poster sources, editable text, image upload, crop-like positioning controls, parchment styles, PNG export, print, and local configuration save.
- Static-host helper: `node developer/local-static-server.cjs`.

These are documented rather than hidden; a later dedicated probability tuning pass can correct them without altering the frozen combat formula.

## Accessibility and hosting

- `prefers-reduced-motion` suppresses animation and transition intensity.
- Battle controls expose a Reduce Motion / Disable Flash choice.
- Poster creation uses Canvas, FileReader, localStorage, and download APIs only; uploaded images are not sent to a server.
- All feature URLs are relative, so the project remains compatible with a GitHub Pages repository subpath.

## Known limits

- Battle is still labelled **Experimental**. The visual system is CSS/HTML driven; it intentionally has no bundled sound or video assets.
- Replay export contains the session seed, fighter IDs, arena, engine version, and action history. An in-app replay import screen is a good next small battle task.
- The automated in-app browser cannot access this environment's localhost server, so visual verification here was limited to headless application tests and a local HTTP asset check. Run `node developer/local-static-server.cjs` and open the shown local URL in a normal browser for final human visual review.
