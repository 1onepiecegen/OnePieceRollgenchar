# V5.5.2 UI Clarity Audit

| Player surface | Change | Result |
|---|---|---|
| Adventure | One primary Generate button, Sandbox route, secondary Roll 10/Roll 100, seed inside Advanced options | Reduced initial decision clutter |
| Battle setup | Explicit Fighter 1/Fighter 2 Saved Character actions | No ambiguous direct-send action |
| Battle Match | Move banner, combat space, live effects, structured history, readable action cards | Important results no longer require reading raw log text |
| Sandbox | Eight visible creator stages with progress, Previous/Next, validation and live review | No enormous all-fields-at-once grid |
| Saved Characters | Stored/no-reroll badge and direct Fighter 1/Fighter 2 actions | Continuity is explicit |

Normal rarity language remains sourced from the prior V5.5 rarity layer; no scientific notation is introduced by V5.5.2.
