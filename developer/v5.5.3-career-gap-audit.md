# V5.5.3 Career gap audit

Career is intentionally labeled **Preview — Experimental**.

Implemented and stateful now:

- Haki, weapon, discipline, recovery, and rival actions record bounded progression changes.
- Mentor search creates a temporary mentor-contact record without rewriting original identity.
- Marine and Cipher Pol actions persist an initial career path and rank.
- Meaningful career actions recalculate the existing bounty model and append a history entry only when its displayed result changes.
- Devil Fruit acquisition retains the one-fruit rule, except for the named existing Blackbeard simulator exception.

Still not implemented:

- Full mission, promotion, recruitment, territory ownership, encounter combat, and a complete career battle loop.
- Automatic Fruit acquisition from a finished Living World event chain.
- Career UI history timeline and player-facing mentor acceptance/training choices.

No combat, threat, bounty, rarity, Voyage Luck, or generation probability formula was altered by this pass.
