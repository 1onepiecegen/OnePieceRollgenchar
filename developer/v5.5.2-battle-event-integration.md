# V5.5.2 Battle Event Integration Map

| Engine event | Rendered component | CSS class | Animation | Normal duration | Accessibility fallback | Actual match integrated |
|---|---|---|---|---:|---|---|
| `attack-telegraph` | `#battle-move-banner`, attacker stage fighter | `battle-event-attack-telegraph`, `power-*`, `element-*` | charge/lunge | 1600 ms | static readable banner | Yes |
| `defense-telegraph` | target fighter, effect detail | `battle-event-defense-telegraph` | charge/perception | 1050 ms | static perception text | Yes |
| `defense-result: guard` | defender and effect detail | `stance-guard` | Armament shield | 1500 ms | shield remains without motion | Yes |
| `defense-result: dodge` | defender and effect detail | `stance-dodge` | lateral afterimage | 1500 ms | position is retained; no motion | Yes |
| `defense-result: counter` | defender and effect detail | `stance-counter` | red focus | 1500 ms | focus border | Yes |
| `defense-result: logia-phase` | defender and effect detail | `stance-dodge`, `element-*` | elemental dispersal presentation | 1500 ms | readable Logia message | Yes |
| `impact` | stage, both fighters, damage float | `minor-impact` / `major-impact` / `legendary-impact` | impact frame, recoil, damage rise | 850 ms | bordered pulse in no-flash mode | Yes |
| Haki state | stage and attack metadata | `haki-armament`, `haki-advanced-armament`, `haki-conqueror-s`, `haki-clash` | coating/clash emphasis | event length | static border/text | Yes |
| Element/fruit state | combat space, banner, effect detail | `element-fire`, `element-magma`, `element-darkness`, etc. | themed arena overlay | event length | themed color and text | Yes |
| `aftermath` | banner/effect detail/turn history | `battle-event-aftermath` | result hold | 1050 ms | same text without flash | Yes |
| winning aftermath | winner panel and banner | `power-finisher` | persistent winner display | persistent | static result | Yes |

The presentation layer reads structured fields added by `engine/battle-presentation-events.js`; it does not parse combat-log text or alter engine damage/RNG.
