# Testing a content batch

1. Run the catalog and canon validation reports.
2. Run a fixed-seed determinism check.
3. Run the 10,000-character smoke and career-continuity checks.
4. Compare the deterministic 100,000 standard and Brutal Grand Line reports with their frozen baseline.
5. Use the real Battle Runtime test for presentation changes.

Do not alter combat, bounty, threat, rarity, Voyage Luck, or distribution formulas during a data batch unless an invariant or repeated systemic regression supplies evidence.
