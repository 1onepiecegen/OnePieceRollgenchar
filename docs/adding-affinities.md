# Adding Element Affinities

`database/elements.js` defines simulator-only battle affinities with `[id, name, strongAgainst, weakAgainst]`. Use established tags such as `fire`, `magma`, `darkness`, `haki`, `fruit-energy`, and `seastone`.

An affinity is not a verdict that one Devil Fruit is weak. It represents a contextual interaction. For example, magma may have an advantage over fire in some simulator exchanges while fire remains a high-value Logia. Haki, mastery, stamina, tactics, and environment still matter.
