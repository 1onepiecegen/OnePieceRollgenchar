# Content contributor guide

The browser app loads authoritative content from `database/`; do not add live catalog entries to `index.html`.

- [Devil Fruits](adding-devil-fruits.md)
- [Mentors](adding-mentors.md)
- [Character presets](adding-character-presets.md)
- [Combat profiles](adding-combat-profiles.md)
- [Techniques](adding-techniques.md)
- [Element affinities](adding-affinities.md)
- [Content tests](testing-content.md)

Every entry needs a stable `id`, `source` (`canon`, `supplemental`, `anime`, `expanded`, or `fan`), and a spoiler-safe `spoilerEra`. Canon facts and simulator interpretation must be labeled separately.
