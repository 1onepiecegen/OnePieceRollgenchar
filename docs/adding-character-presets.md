# Adding Character Presets

Presets in `database/character-presets.js` are complete authored templates built from a curated combat profile. A preset contains `id`, `name`, `source`, `era`, `characterId`, `combatProfileId`, `identity`, `mentorHistory`, `fruitIds`, `weaponIds`, `haki`, `progression`, `personality`, `worldProfile`, `referenceBounty`, `variableFields`, and `provenance`.

Canon presets display an unmodified known reference bounty when one is available. Any edit becomes an alternate simulator build. OC and unrestricted presets must use a source label and do not receive a natural-roll rarity probability.
