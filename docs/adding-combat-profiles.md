# Adding Combat Profiles

Combat profiles live in `database/combat-profiles.js`. They are curated simulator interpretations, not official numeric power levels. Use `id`, `characterId`, `name`, `era`, `source`, `spoilerEra`, `physical`, `mental`, `willpower`, `haki`, `fruitId`, `weaponMastery`, `foundationIds`, `disciplineIds`, `techniqueIds`, `advancedStateIds`, `behaviorProfileIds`, `balanceBand`, `confidence`, and `evidenceNotes`.

Link the profile to a character reference. Keep abilities, stamina, weapons, behavior, and context separate rather than reducing a canon fighter to one score. The Battle page labels these profiles Experimental.
